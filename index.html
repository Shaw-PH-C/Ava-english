📚 今日 10 大退換貨核心單字
  • Exchange (更換 / 交換)
  • Return (退貨)
  • Refund (退款)
  • Too small / Too big (太小 / 太大)
  • Size up / Size down (大一號 / 小一號)
  • Store credit (購物金 / 店鋪折抵額度)
  • Defective (有瑕疵的 / 有問題的)
  • Policy (政策 / 規定)
  • Original condition (全新未拆封原狀 / 原本狀態)
  • Proof of purchase (購買證明 / 收據)
🗣️ 今日實戰對話句型
"This is a bit too small. Could I exchange it for a size up, and do you need the receipt?"
(這件有點太小了。我可以換大一號嗎？請問需要看收據嗎？)
📝 記憶小測驗（進階實戰・共 5 題）
1. 如果你買了一件外套發現穿起來太緊，想請店員幫忙換「大一號」，正確的英文說法是？
2. 當店員告訴你該精品店「不接受現金退款，但可以提供店鋪折抵額度下次使用」，這個折抵額度英文叫？
3. 前往櫃檯辦理退換貨時，店員通常會要求你出示「購買證明」或發票，英文是？
4. 如果你發現剛買的精品包包縫線有瑕疵，想向店員反應它是「有缺陷/有瑕疵的」，要用哪個形容詞？
5. 辦理退貨時，商品必須保持「全新未拆封的原狀」，英文專業說法是？
